## Область и ограничения

Весь репозиторий локально не клонировался. Для проверки patch восстановлены 10 изменяемых исходных документов и сохранённый MW subtree. Совместимость с чужими незакоммиченными изменениями или более новым commit необходимо проверить отдельно. Патч не удаляет старые документы, не меняет source/CI/migrations и не назначает новые разрешения scope.

Не выполнялись Rust build/tests/doctests, PostgreSQL migrations/roles/races, запуск server/worker/HTTP/MCP, браузерная или официальная клиентская совместимость, реальные импорт/экспорт/backup/restore, полный standards-validator OpenAPI и повторная доступность всех внешних URL. Независимое review проекта решений также не выполнялось.

Полная нормативная и историческая документация остаётся в исходном репозитории и доступна по pinned-ссылкам. Этот ZIP — готовый комплект руководств и roadmap плюс неизменённый MW-пакет, но **не полный backup репозитория**.

## Повторная проверка

```bash
python docs/maintenance/validate_documentation.py .
```

Нужны Python 3.10+, `markdown-it-py`, `jsonschema` и Bash для синтаксической проверки Bash-блоков. Валидатор не обращается к сети и не пишет результат в файлы. Машиночитаемый результат этого прогона находится в [validation-result.json](validation-result.json), состав изменений — в [scope-result.json](scope-result.json).

Контрольные суммы: [payload-manifest.json](payload-manifest.json). Манифест не включает себя и итоговый JSON результата, чтобы не создавать самоссылочный хеш. Он фиксирует остальные файлы, в том числе этот отчёт. Новые редакции должны создавать новое проверяемое свидетельство, а не менять старое на PASS без прогона.
