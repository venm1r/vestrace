## Mandatory merge rule

A PR may be reviewed in parallel when independent, but it MUST NOT merge before every dependency in the table is satisfied.

## Universal PR exit conditions

Every future PR must provide:

1. exact normative requirement IDs;
2. explicit authoritative-state ownership impact;
3. forward-only migration/backfill plan or `none`;
4. stale/crash/retry/ambiguity semantics where applicable;
5. security/data-governance impact;
6. executable evidence plan;
7. current-implementation documentation update plan;
8. known limitations introduced or preserved.
