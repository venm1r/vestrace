# v0.3 Learn — Detailed Contracts L1–L3

**Status:** approved documentation plan  
**Implementation changes authorized:** none

## PR-L1 — Evaluation Fact v2

### Requirements

`LRN-001`, `LRN-002`, `LRN-006`, `LRN-007`, `LRN-008`.

### Contract

```text
EvaluationFact
├─ evaluation_id
├─ workspace_id
├─ execution_ref
├─ subject_ref
├─ evaluator_kind
├─ evaluator_identity/version
├─ metric/schema identity
├─ value/result
├─ evidence_refs[]
├─ policy_ref?
├─ recorded_at
└─ provenance
```

Evaluator authority is explicit:

```text
DETERMINISTIC
HUMAN
EXTERNAL_SYSTEM
MODEL_JUDGE
HEURISTIC
```

No universal score collapses these authority classes.

### Compatibility

Existing generic evaluation records may be retained and bridged when execution/subject/evaluator identity can be proven. Ambiguous legacy records remain legacy facts and are not promoted to authoritative learning evidence.

### Acceptance

- exact execution/model/tool/policy revisions can be traced;
- raw evaluation remains immutable;
- model-judge result is distinguishable from deterministic/human evidence;
- deleting learned projection does not delete raw evaluation history.

## PR-L2 — Learned Projection / Proposal Boundary

### Requirements

`LRN-002..005`, `LRN-007..008`, `CAP-003`, `CAP-014`.

### Contract

```text
LearningObservation
    ↓
LearnedProjection
    ↓
ChangeProposal
    ↓
normal governed mutation/versioning
```

```text
LearnedProjection
├─ projection_id
├─ subject_ref
├─ evidence_refs[]
├─ method/version
├─ confidence
├─ generated_at
└─ expiry/revalidation metadata
```

```text
ChangeProposal
├─ target_asset_ref
├─ proposed_change
├─ evidence_refs[]
├─ expected_revision
├─ risk
└─ required_authority
```

### Hard boundary

Learning may propose changes to agent/skill/workflow/policy-adjacent configuration but cannot:

- mutate assets in place;
- increase capabilities;
- bypass approvals/policy;
- overwrite raw evaluation facts.

### Acceptance

- learned projection is rebuildable;
- proposal pins target revision;
- stale proposal fails/replans;
- no path from evaluation to authority escalation exists.

## PR-L3 — COGNITION Benchmark / Conformance Gate

### Requirements

`LRN-001..008`, applicable `QUAL-006`, `QUAL-007`, `QUAL-010`, `MEM/RET` dependencies inherited from MEMORY profile.

### Benchmark families

```text
Recall
Temporal Recall
Contradiction Resolution
Provenance
Long-Horizon Memory
Context Selection
Cross-Session Continuity
Forgetting
Access Isolation
Shared Cognition (only where sharing enabled)
```

### Hard gates

- restricted-data leakage = 0;
- provenance coverage for required cases = 100%;
- stale-current-truth masking = 0 in normative scenarios;
- skipped required MUST = qualification failure.

### Metrics

Quality metrics such as Recall@k/MRR may have thresholds, but cannot compensate for hard-gate failure.

### Exit gate

`v0.3 Learn` is claimable only when COGNITION requirements have executable cases and asset-learning paths remain governed/versioned.
