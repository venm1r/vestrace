## PR-E1 — ExternalEffectIntent + Adapter Contract

### Requirements

`EXT-001..005`, `EXT-011`, `EXT-014..015`, `EXT-018`.

### Contract

```text
ExternalEffectIntent
├─ effect_id
├─ run/step ref
├─ actor
├─ adapter
├─ operation
├─ target
├─ normalized arguments digest
├─ redacted arguments
├─ expected effect
├─ preconditions[]
├─ risk
├─ reversibility
├─ delivery semantics
├─ idempotency profile
├─ required capability
├─ budget reservation ref?
└─ created_at
```

Adapter must declare:

```text
delivery_semantics
idempotency
retry_safety
reconciliation_method
reversibility
dry_run_support
secret/data handling
```

### Acceptance

- intent persisted before dispatch;
- prepare and dispatch capabilities are distinct;
- material intent mutation invalidates approval;
- secret plaintext absent from durable intent/audit.

## PR-E2 — Effect Dispatch + Receipt + UNKNOWN

### Requirements

`EXT-002`, `EXT-006..009`, `EXT-014..018`.

### Lifecycle

```text
PREPARED
→ AUTHORIZED
→ DISPATCHING
→ ACKNOWLEDGED | FAILED | UNKNOWN
→ CONFIRMED | RECONCILING | UNKNOWN
```

### Receipt

```text
ExternalEffectReceipt
├─ effect_id
├─ provider
├─ dispatched_at
├─ response_class
├─ external_resource_id?
├─ external_version?
├─ response_digest?
├─ outcome_status
└─ evidence_refs[]
```

### Rules

- timeout after dispatch => UNKNOWN unless absence is proven;
- ACK != business outcome;
- UNKNOWN never auto-converts to FAILED;
- retry only if adapter proves retry-safe semantics.

### Acceptance

Fault at `after dispatch / before receipt` recovers to UNKNOWN without duplicate unsafe effect.

## PR-E3 — Reconciliation / Compensation

### Requirements

`EXT-010..013`, `REC-005..006`.

### Reconciliation evidence priority

1. provider idempotency lookup;
2. exact external resource id;
3. operation status endpoint;
4. ETag/version/revision;
5. content hash;
6. transaction/reference id;
7. bounded search by unique marker;
8. governed human verification.

### Compensation contract

Compensation is a new ExternalEffectIntent with `compensates(effect_id)` relation. Original effect remains immutable history.

### Acceptance

- reconciliation evidence retained;
- unresolved ambiguity remains UNKNOWN;
- compensating effect gets independent authorization/risk/budget;
- compensation is never represented as rollback.

## PR-E4 — External-effect Fault Suite / Adapter Qualification

### Requirements

All applicable `EXT-*`, `QUAL-008`, `QUAL-011`, `QUAL-012`.

### Required fault points

```text
before intent persistence
after intent persistence / before authorization
after authorization / before dispatch
after dispatch / before receipt
after receipt / before confirmation
after confirmation / before Run step commit
```

### Adapter qualification matrix

For each adapter verify:

```text
authorization
classification/redaction
idempotency declaration
retry behavior
timeout semantics
receipt
reconciliation
cancellation
dry-run class
secret handling
known limitations
```

### Exit gate

`v0.6 Connect` is claimable only when each enabled side-effect adapter has explicit delivery semantics and passes its applicable fault/negative suite.
