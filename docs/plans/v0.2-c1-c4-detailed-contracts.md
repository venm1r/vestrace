## PR-C1 — Generic Temporal Event and Memory Revision Model

### Requirement mapping

| Requirement | Planned evidence |
|---|---|
| TMP-001 | event fixture proves `occurred_at` and `recorded_at` differ |
| TMP-002 | event with unknown occurrence time remains valid |
| TMP-003 | future/past validity independent of recording time |
| TMP-006 | stale expected revision rejected |
| TMP-007 | conflict result contains current revision, no overwrite |
| TMP-008 | equal/ordered wall clocks do not establish causality |
| MEM-001 | stable Memory identity + immutable revisions |
| MEM-002 | semantic mutation creates new revision |
| MEM-003 | active revision belongs to same Memory |
| MEM-004 | revision number monotonic/immutable |
| MEM-008 | invalid validity interval rejected |
| MEM-009 | invalid confidence/importance rejected |
| MEM-010 | structured payload requires schema identity/version |
| MUT-001 | mutation audit captures actor/target/expected state/reason/result |
| MUT-002 | correction creates new revision rather than overwrite |

### Schema contract

Additive only. Future migration may add:

```text
events.occurred_at nullable
events.recorded_at not null
events.correlation_id nullable
events.causation_id nullable
memories.state_revision not null
memory_revisions.valid_from nullable
memory_revisions.valid_until nullable
memory_revisions.classification not null
memory_revisions.change_reason nullable
memory_revisions.created_by nullable/typed
memory_revisions.canonical_hash not null
```

Backfill rules:

- existing event timestamp -> `recorded_at`;
- `occurred_at = NULL` unless provable;
- open validity remains NULL/NULL;
- actor is not fabricated;
- canonical hash is generated deterministically from canonical serialized content.

### Failure semantics

- stale state revision -> explicit conflict;
- invalid validity interval -> reject before commit;
- hash mismatch on persisted revision -> integrity finding later, never silent rewrite;
- missing historical actor remains unknown, not synthetic user identity.

### Exit gate

C1 is complete only when temporal identity is sufficient for later `KNOWN_AS_OF` and `VALID_AS_OF` without inventing data.

## PR-C2 — EvidenceRef / Derivation v2

### Requirement mapping

| Requirement | Planned evidence |
|---|---|
| MEM-005 | active Memory has admissible source/evidence |
| MEM-006 | derived Memory requires Derivation |
| MEM-012 | provenance closure resolves to source evidence/human authority |
| ARC-006 | correction/derivation preserves original history |
| GOV-003 | derived classification does not automatically decrease |

### Domain contract

```text
EvidenceRef =
  EventRef
  ArtifactRevisionRef
  DocumentRef
  MemoryRevisionRef
  ModelExecutionRef
  ToolResultRef
  ExternalEffectReceiptRef
  HumanFeedbackRef
  FederatedEvidenceRef
  ExternalReference
```

```text
Derivation
├─ derivation_id
├─ method
├─ input_refs[]
├─ output_ref
├─ execution_ref?
├─ model_ref?
├─ policy_ref?
├─ created_by
└─ created_at
```

### Compatibility contract

Existing `MemorySource`/provenance data is bridged, not deleted. A legacy source can map to an EvidenceRef only when target identity can be determined. Otherwise it remains a legacy provenance record and blocks claims of full provenance closure.

### Security contract

Evidence references store identity/provenance, not secret payload copies. Secret-bearing sources remain referenced through governed objects.

### Exit gate

Every newly derived canonical Memory must have resolvable provenance closure or fail creation/activation according to policy.

## PR-C3 — Claim / Assessment / Conflict Core

### Requirement mapping

| Requirement | Planned evidence |
|---|---|
| MEM-013 | Claim and Memory remain distinct types |
| MEM-014 | Supported != external truth |
| MEM-015 | loss of all admissible evidence triggers revalidation |
| MEM-016 | semantic conflict remains explicit |
| MEM-017 | no universal latest-wins resolution |
| MEM-018 | conflict resolution stores basis/evidence/policy/human decision |
| MEM-019 | supersession preserves history |
| RET-003 | unresolved conflict is surfaced by retrieval |
| RET-008 | retrieval inclusion never increases authority |

### Domain contract

```text
Claim
├─ claim_id
├─ workspace_id
├─ proposition/schema identity
├─ validity
├─ lifecycle/status
└─ state_revision

ClaimEvidenceLink
├─ claim_id
├─ evidence_ref
├─ relation: supports|contradicts|context
└─ admissibility metadata

ClaimAssessment
├─ claim_id
├─ status
├─ basis refs[]
├─ policy/version?
├─ evaluator authority
└─ recorded_at

Conflict
├─ conflict_id
├─ competing refs[]
├─ status
└─ resolution ref?
```

### Migration contract

No blind Memory -> Claim conversion. Only deterministic propositional records may be migrated automatically. Ambiguous memories stay Memory-only until explicit classification/reconciliation.

### Conflict semantics

`Supported -> Contested` can occur when admissible contradiction is recorded. Resolution creates a new assessment/resolution fact; it does not delete losing evidence.

### Exit gate

C3 is complete when current supported cognition can be represented without pretending Memory itself is truth.

## PR-C4 — Cognitive Mutation / Reconciliation Service

### Requirement mapping

| Requirement | Planned evidence |
|---|---|
| MUT-001 | mutation envelope persisted |
| MUT-002 | corrections append revisions/facts |
| MUT-003 | deterministic reconciliation uses higher authority |
| MUT-004 | semantic ambiguity not treated as repair |
| MUT-005 | policy-guided reconciliation pins policy version |
| MUT-006 | human-required path cannot auto-complete |
| MUT-007 | no generic Task/Action aggregate introduced |
| MUT-008 | reconciliation result links competing inputs/evidence |
| TMP-006 | expected revision required for competing canonical mutation |
| TMP-007 | version mismatch returns conflict |
| TMP-009 | leases do not alter authority/revision |
| TMP-010 | append streams preserve monotonic order |

### Mutation envelope

```text
CognitiveMutation
├─ mutation_id
├─ actor
├─ workspace
├─ target_ref
├─ expected_state_ref/revision
├─ intent/reason
├─ evidence_refs[]
├─ policy_ref?
├─ requested_change
└─ recorded_at
```

### Reconciliation modes

```text
DETERMINISTIC
POLICY_GUIDED
SEMANTIC
HUMAN_REQUIRED
```

Rules:

- DETERMINISTIC requires authority ordering proof;
- POLICY_GUIDED pins exact policy version;
- SEMANTIC may propose but cannot fabricate certainty;
- HUMAN_REQUIRED remains unresolved until governed human decision.

### Idempotency/concurrency

Mutation command must have stable idempotency identity where retried. Same idempotency key + different material payload -> conflict. Expected revision mismatch -> no state change.

### Exit gate

C4 is complete when every significant cognitive correction/reconciliation has a reproducible reason, inputs, authority basis and resulting fact/revision.
