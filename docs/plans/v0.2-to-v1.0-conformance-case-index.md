# Vestrace v0.2 → v1.0 — Global Conformance Case Index

**Status:** documentation-only verification index

## Purpose

Provide one stable inventory of planned conformance cases across all release phases. Detailed semantics remain in the phase matrices.

## Phase 0

```text
CONF-CORE-001  Optimistic version conflict is rejected
CONF-MEM-001   Memory revision identity/history remains stable
CONF-RET-001   ContextPack hard budget is respected
CONF-IDW-001   Foreign workspace data is denied
CONF-CAP-001   Missing capability denies protected operation
```

These cases bootstrap traceability; they do not qualify a profile by themselves.

## v1.0 Trust

Families:


Hard properties:

- unfinished work classified explicitly;
- UNKNOWN effect reconciled before unsafe action;

## Global case result semantics

```text
PASS
FAIL
SKIPPED
BLOCKED
INCONCLUSIVE
```

For a required MUST case:

```text
PASS         → eligible evidence
FAIL         → profile fails
SKIPPED      → profile fails
INCONCLUSIVE → profile fails
BLOCKED      → profile incomplete/fails until resolved
```

## Evidence minimum

Every executed case records at least:

```text
case_id
requirement_ids[]
profile
status
source_revision
build_digest
suite_version
started_at/completed_at
evidence refs
failure/limitation metadata
```

Higher profiles additionally bind environment/config/provider/backend identities.

## No aggregate-score shortcut

No weighted score can override:

- authorization bypass;
- cross-workspace leak;
- restricted-data leak;
- unsafe external-effect retry;
- false trust transition;
- failed deletion semantics;
- required MUST failure/skipped/inconclusive.
