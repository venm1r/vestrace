## C8 — CORE + MEMORY Gate

Required aggregate scenarios:

1. **Long-lived fact correction:** create → revise → supersede → current retrieval → historical retrieval.
2. **Late evidence:** KNOWN_AS_OF differs from RECONSTRUCTED_AS_OF.
3. **Contradiction:** contested Claim never silently becomes current truth.
4. **Workspace isolation:** HTTP/MCP/internal retrieval cannot disclose foreign workspace content.
5. **Projection rebuild:** delete/corrupt derived search state; rebuild yields equivalent retrieval without canonical mutation.
6. **Migration fixture:** pre-v0.2 data migrates with no invented temporal/authority facts.
7. **Budget:** ContextPack always respects hard bound and provenance.
8. **Stale concurrency:** concurrent Memory update rejects lost write.

## Gate policy

`CORE + MEMORY` can be declared only if:

```text
all applicable MUST cases = PASS
required SKIPPED = 0
required INCONCLUSIVE = 0
security leakage = 0
unresolved migration integrity failures = 0
```

Metric quality does not compensate hard-gate failure.
