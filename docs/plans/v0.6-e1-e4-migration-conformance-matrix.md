# v0.6 Connect — Migration / Conformance Matrix (E1–E4)

**Status:** documentation-only implementation contract

## E1 — ExternalEffectIntent + Adapter Contract

### Migration

Add intent storage, adapter metadata, delivery/idempotency/reconciliation/reversibility declarations and prepare/authorize state.

Existing tool invocation history is not reclassified as external effect unless side-effect semantics are deterministically known.

### Cases

| Case | Requirements | Expected result |
|---|---|---|
| CONF-EXT-001 Intent first | EXT-001 | immutable intent persisted before dispatch |
| CONF-EXT-002 Authorization | EXT-002 | capability/policy/budget gates pass before dispatch |
| CONF-EXT-003 Delivery declaration | EXT-003/004 | adapter declares semantics; no universal exactly-once claim |
| CONF-EXT-004 Retry contract | EXT-005 | retry decision comes from adapter contract |
| CONF-EXT-005 Secret handling | EXT-018 | secret plaintext absent from intent/audit |

## E4 — Fault Suite / Adapter Qualification

Deterministic fault points:

```text
before intent persist
after intent persist / before authorization
after authorization / before dispatch
after dispatch / before receipt
after receipt / before outcome confirmation
after outcome / before Run-step commit
```

Required scenarios:

1. idempotent provider create + timeout → reconcile by key → one remote object;
2. at-most-once unsafe action + timeout → no automatic retry;
3. crash after dispatch before receipt → restart → UNKNOWN → reconciliation;
4. stale ETag/version → no dispatch;
5. approved intent material changed → authorization invalid;
6. compensation preserves original effect history;
7. secret references resolved ephemerally, never persisted plaintext.

Gate:

```text
required EXT MUST PASS
unsafe ambiguous retries = 0
false CONFIRMED outcomes = 0
unqualified active effect adapters = 0 for claimed AUTONOMY scope
required SKIPPED/INCONCLUSIVE = 0
```

## Global migration rules

1. Legacy tool/model calls remain their original record type unless deterministic classification proves an external-effect migration.
2. Never synthesize `CONFIRMED` from historical HTTP success alone.
3. Historical timeout without sufficient evidence remains unknown/legacy-ambiguous.
4. Receipt/outcome/reconciliation history is append-oriented.
5. External-effect operations use the single Run execution boundary.
