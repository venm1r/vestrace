## Traceability rules

1. Every normative MUST has exactly one **primary implementation owner PR** and may have multiple supporting PRs.
2. Gate PRs do not silently implement missing semantics; they verify them.
3. A requirement cannot move to a later phase just because implementation is difficult; movement requires explicit spec/ADR change.
4. `PASS` may only be claimed from executable evidence, never from this matrix.
5. If a future PR changes a requirement's observable semantics, the traceability map and normative catalog must be updated together.
