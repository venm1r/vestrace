# v0.3 Learn — Migration / Conformance Matrix (L1–L3)

**Status:** documentation-only implementation contract

## L1 — Evaluation Fact v2

### Migration

Add exact target/execution/model/tool/policy/evaluator/evidence references to evaluation storage.

Backfill:

- preserve existing score/status/summary;
- exact refs remain NULL/legacy-unresolved unless provable;
- do not infer evaluator authority from display name or evaluation type;
- existing evaluation rows stay historical facts.

### Cases

| Case | Requirements | Expected result |
|---|---|---|
| CONF-LRN-001 Exact target refs | LRN-001 | new feedback resolves exact execution/model/tool/policy revisions |
| CONF-LRN-002 Evaluator kind | LRN-001, LRN-006 | deterministic/human/heuristic/model-judge remain distinguishable |
| CONF-LRN-003 Evidence retention | LRN-007 | conclusion links underlying measurements/evidence |
| CONF-LRN-004 Legacy uncertainty | ARC-007 | migrated legacy row does not gain invented authority/target precision |

## L2 — Learned Projection / Proposal Boundary

### Schema

Add typed learned projection/proposal objects with provenance, status and target revision preconditions.

No automatic mutation of capability/policy/agent authority.

### Cases

| Case | Requirements | Expected result |
|---|---|---|
| CONF-LRN-005 Raw vs learned | LRN-002 | deleting learned projection leaves raw evaluation facts intact |
| CONF-LRN-006 No self-escalation | LRN-003/004 | learned recommendation cannot grant capability or bypass governance |
| CONF-LRN-007 Versioned asset proposal | LRN-005 | proposed Agent/Skill/Workflow change creates new versioned proposal/revision path |
| CONF-LRN-008 Provenance | LRN-007/008 | learned recommendation resolves source evaluations; raw history preserved |

## L3 — COGNITION Gate

Required benchmark/property families:

- Recall;
- Temporal Recall;
- Contradiction Resolution;
- Provenance;
- Long-Horizon Memory;
- Context Selection;
- Cross-Session Continuity;
- Forgetting;
- Access Isolation.

Hard gates:

```text
restricted-data leakage = 0
required provenance coverage = 100%
no authority self-modification
required LRN MUST cases PASS
```

Quality metrics (Recall@k, MRR, stale-memory rate, contradiction masking rate) are reported but cannot compensate hard-gate failure.

## Migration rules

1. Existing evaluation data is preserved verbatim as historical evidence.
2. New exact references are populated only when deterministic linkage exists.
3. Learned projections are always rebuildable/revisable from raw evaluation facts.
4. No migration converts an evaluation score into a policy/capability decision.
